让网页录音拿到
本地音频，而非真实麦克风

在 *.tsinghuaelt.com 与 *.izhixue.cn 站点上，本插件允许你注入本地音频文件。适用于自动化测试、功能演示与无障碍辅助。

安装

1

开启开发者模式

打开 chrome://extensions 或 edge://extensions，右上角开启「开发者模式」。

2

加载扩展

下载 Release 压缩包并解压，点击「加载解压缩 / 未打包的扩展」，选择解压后的目录。

3

登录使用

访问 *.tsinghuaelt.com 并登录，扩展即自动生效。

功能特性

虚拟麦克风注入

包装 getUserMedia / enumerateDevices，录音自动返回音频库中的本地文件，并可自动播放。

网页音频捕获

目标页播放音频时，右下角悬浮球一键捕获，「＋ 加入音频库」后自动设为当前音频。

白噪音混音

内置雨声、海浪、溪流、雷雨四种白噪音，可与本地音频混合输出。

持久化音频库

chrome.storage.session 管理运行时状态，IndexedDB vmic-db 持久保存音频文件。

一键切换

设置页关闭「启用注入」即可恢复真实麦克风，点列表行即时切换当前文件。

工作原理

注入的音频经 Web Audio 图混合后，作为伪麦克风流交还给页面。

使用

  • 导入本地音频，或通过悬浮球从网页捕获音频
  • 点列表行切换当前文件
  • 点击录音即可自动播放音频
  • 左下角设置按钮可调整延时等参数

const rec = new MediaRecorder(stream), chunks = [];
rec.ondataavailable = (e) => chunks.push(e.data);
rec.onstop = () => {
  const a = document.createElement('a');
  a.href = URL.createObjectURL(new Blob(chunks));
  a.download = 'vmic-test.webm'; a.click();
};
rec.start(); setTimeout(() => rec.stop(), 4000);
